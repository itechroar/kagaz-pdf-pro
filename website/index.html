AI assistant

Self-host in a minute

git clone https://github.com/itechroar/kagaz-pdf-pro
cd kagaz-pdf-pro
cp .env.example .env     # set KAGAZ_AUTH_ADMIN_PASSWORD
docker compose up -d

Then open http://localhost:8080. See the deployment guide in the repository for HTTPS, SSO, AI keys and offline setups.
