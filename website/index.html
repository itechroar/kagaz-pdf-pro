What you get

Full PDF toolkit

Dozens of tools behind a REST API and a modern web editor, with tool chaining and automation pipelines.

Users and SSO

Local accounts, API keys, per-user quotas and OpenID Connect sign-in with PKCE.

Audit log

A record of every change made through the API, with an admin page to review it.

AI assistant

Summarise and ask questions about any PDF using Anthropic, OpenAI, Gemini, Ollama and more. Scanned files are read with OCR.

Offline ready

Runs with no internet. Offline mode keeps AI traffic on local models only.

Hardened by default

Hashed passwords and keys, login rate limiting, strict security headers and secure cookies over HTTPS.

Self-host in a minute

git clone https://github.com/itechroar/kagaz-pdf-pro
cd kagaz-pdf-pro
cp .env.example .env     # set KAGAZ_AUTH_ADMIN_PASSWORD
docker compose up -d

Users open http://localhost:8080 and sign in or create an account; administrators use the separate site at http://localhost:8081. See the deployment guide in the repository for HTTPS, SSO, AI keys and offline setups.
